# Manju Malateshappa — Personal Portfolio

Live site: **https://manju-malateshappa.github.io/**

Personal portfolio and résumé site for Manju Malateshappa, AI/ML Architect & Engineering Leader. Vanilla static HTML, CSS, and JavaScript — no build step, no framework. Deployed via GitHub Pages from `main`.

## Local development

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Files

- `index.html` — single page, all sections inline (hero, about, experience, skills, projects, achievements, contact).
- `styles.css` — theme, layout, dark/light CSS variables, responsive breakpoints.
- `app.js` — vanilla JS for theme toggle, mobile nav, smooth scroll, and the live GitHub project feed.
- `assets/` — optimized profile photo and downloadable résumé PDF.
- `.nojekyll` — disables Jekyll on GitHub Pages so files are served as-is.
